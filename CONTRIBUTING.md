# Contributing to NXD Rust Frontend

Thank you for your interest in contributing to the NXD Rust Frontend project.

## Current Project Status

This repository contains the in-progress Rust frontend rewrite for the NXD compiler.

The Python frontend remains the reference implementation (found in the nxd_language repository) during migration and parity testing. The primary goal at this stage is correctness and parity with the existing implementation rather than optimization or large-scale refactoring.

## Before Contributing

Please:

1. Read the README.
2. Review existing issues and pull requests.
3. Open an issue before beginning substantial work.
4. Keep changes focused and easy to review.
